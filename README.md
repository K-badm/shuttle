# シャトル組み合わせ

バドミントンサークルの練習日に、ダブルスの組み合わせを自動で作るアプリです。
スマホのホーム画面に置けて（PWA）、メンバーは自分のスマホで組み合わせを見られます。

## 見てみる

`index.html` をダブルクリックすると、ブラウザで開きます（この端末だけに保存されます）。

## アプリにする・メンバーと共有する

`SETUP.md` の手順で、Firebase（データの保存先）と GitHub Pages（URL）を用意してください。

## Claude Code で開発を続ける

ターミナルで次のように入力します。

```
cd ~/Documents/badminton-matcher
claude
```

仕様とコードの説明は `CLAUDE.md` に書いてあります。Claude Code は起動するとこのファイルを自動で読むので、すぐに「〇〇を追加して」と頼めます。

最初に頼むことの例：

- 「組み合わせロジックを scheduler.js に分けて、テストを書いて」
- 「管理者画面にパスワードを付けて」
- 「メンバー画面の番号を受付順にして」
